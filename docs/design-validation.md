# 自动校验

校验按设计者指定的安装规则及连接意图工作，不判断电路功能、元件参数或仿真结果。自动布局与自动布线暂未实现，待本阶段使用效果明确后评估可行性。

## 插孔和外壳

- 元件引脚与跳线两端各占一个插孔，默认不允许共孔。跳线中途经过的孔位、直角折点不占孔；贴片元件与锡线不占插孔。
- 放置、复制、移动、旋转、修改引脚布局及线路端点都会阻止新增冲突。拖动预览可经过冲突位置，但释放时会取消冲突操作；取消操作不写入撤销历史。
- 特殊安装时可为元件或跳线勾选「忽略碰撞」。放置前的属性面板也能设置放置元件 / 新跳线的豁免。豁免仅影响涉及该对象的物理冲突；其他对象仍检查，实际连通关系也不改变。
- 如需从元件引脚接跳线，可把跳线端点插在邻孔，再用锡线把两个焊盘接通，不必共孔。
- 每个元件可开启外壳碰撞，并手动设置左边界、上边界、宽度和高度。单位为孔距，坐标相对元件基准孔，在元件旋转前的坐标系内定义，随元件旋转。
- 外壳仅与同面已启用的外壳比较，边界相接允许，内部重叠为冲突。焊盘面还检查锡线是否穿过外壳内部；贴片默认建议边界位于两个焊盘之间，端子可正常焊接接线。前面的跳线是否从外壳上方经过涉及高度，本阶段不按二维交叉阻止。
- 尚未启用外壳检查的对象没有已知实体边界。画布原有引脚示意框不能作为实物外壳尺寸。
- 开启检查、调整边界、关闭碰撞豁免属于规则设置，允许完成并在校验页显示现有冲突；后续几何操作不得制造新的冲突。
- 旧项目含冲突仍可打开，保持原有布局并列出问题，不自动挪动、删除或标记豁免。减少已有冲突的操作允许。

## 逻辑连接和 NC

在「逻辑」工具中点击两个元件引脚，声明它们同属一个连接组；翻面或使用并排视图可以跨面声明。连接已有两个组时，会把两组归并。该操作可撤销，并不创建实际导线。

选中元件后，也可以逐脚选择「未声明」「连接组」或「NC」。同名连接组代表同一组，组名区分大小写。一个引脚也可声明独立组，例如外部接口。

- 同组引脚必须通过实际锡线、跳线和焊盘连通。
- 不同组默认必须隔离。
- NC 表示不与其他元件引脚实际相连，多个 NC 相互连接同样报错。只接了一段不通向其他引脚的尾线不会触发 NC 错误。
- 文字标注为 `NC` 不会自动成为 NC 声明，需要用户手动选择。
- 所有元件引脚，包括贴片两端，都已分组或声明 NC 后，才开启连通性检查。跳线端点与锡线不是需要声明的元件引脚。
- 增加未声明引脚、清除声明或复制未重新分组的元件后，连通性检查暂停并显示待声明数量；物理碰撞检查始终独立运行。
- 移动、旋转、修改名称或标注保留引脚关系。删除引脚则删除该引脚的声明，新加引脚默认未声明。逻辑关系随引脚保留，不绑定原来的孔位。
- 复制元件保留明确的 NC 状态和物理属性，清除连接组，避免自动接入原元件的网络。独立元件文件同样去除原板组名与引脚身份。

## 实际连通模型

以实际物理孔位为节点，翻面显示的镜像不改变节点身份。

1. 同一个焊盘上的元件端子、跳线端点和锡线接点视为连通，即使通过「忽略碰撞」允许了共孔。
2. 锡线沿途经过的全部焊盘连通；同面锡线交叉、重叠、T 接或端点相接均连通。
3. 跳线只连接首末两端，中间经过孔位、折点或交叉其他导线不产生连接。
4. 元件内部绝不按导线合并引脚，包括贴片电阻、电容。连接组表达直接导通关系，不表示经过电阻、电容之后仍属同组。

因此模型能够报告同组漏接、不同组误短接及 NC 错接。引脚没有实际接线、跳线端点悬空另作警告，不阻止已声明的连接规则通过。只有逻辑声明完整时才生成这些电气检查结果。

## 定位与保存

右侧「校验」页列出物理冲突、待声明引脚及电气错误 / 警告，点击后选中相关对象并放大定位。勾选「显示逻辑连接与 NC」可查看紫色虚线和 NC 标记，逻辑线及错误高亮不进入 PNG；启用的外壳范围会随布局导出。

项目和独立元件格式升级为 `1.3.0`，旧格式逐级升级。旧文件不会自动生成组名、NC 或外壳规则。高于读取工具支持的中版本仍需升级工具，避免旧工具静默丢失新规则。
